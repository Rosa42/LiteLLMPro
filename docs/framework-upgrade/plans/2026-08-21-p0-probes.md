# P0 探针执行计划（探针 A / 探针 B）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (or subagent-driven-development) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用运行时证据判定两件事：MiniMax-M3 在 Anthropic Messages 上能否识图；本机网关 `async_pre_call_hook` 对 `data["messages"]` 的改写能否到达 Messages 上游。两项通过后才允许拆规格；本计划**不**实现视觉翻译或记忆模块。

**Architecture:** 探针 A 绕过网关 IMAGE 门控，直连 MiniMax 官方 Anthropic 端点（当前 `plans.yaml` 未给 M3 声明 `image`，经网关带图会被 `FEATURE_UNSUPPORTED` 拒绝，不能当第一证据）。探针 B 在 live 代理的 `POST /v1/messages` 上注入客户端请求里不存在的 marker；上游出口用 mock 布尔命中（实验室）或模型回显（实网）证明，禁止日志打印完整 prompt / Key / 图片 data。

**Tech Stack:** LiteLLM v1.90.5 本机 proxy、`shared_quota_router` CustomLogger、Anthropic Messages、现有 `scripts/probe_anthropic_support.py` 风格的 urllib 探针、可选 `mock_provider`。

**依据：** `docs/framework-upgrade/design-proposal.md` §16 P0、§7.1、Q6。

**非目标：** `glm-5.2-vision` 配方、剥图流水线、Chat/Responses 探针、向量库、改 `upstream/litellm`。

**通过标准（写进报告后才能拆 spec）：**

| 探针 | PASS | FAIL | INCONCLUSIVE |
|------|------|------|----------------|
| A | MiniMax Messages 200 且回复表明收到了图 | 4xx/5xx 明确拒图，或明确说没看到图 | 传输错误、超时、模型不按指令回答 |
| B | 客户端 body **不含** marker，上游出口 **含** marker | 200 且 mock/抓包证明上游 body 无 marker | 实网模型不回显且没有 mock 证据 |

B FAIL → 按提案改画挂点（门控豁免 IMAGE + strategy mutation），本计划只记录结论，不实现替代挂点。

## Task 1: 探针 A — MiniMax-M3 直连识图

**Files:**
- Create: `local-llm-router/scripts/p0_probe_a_minimax_vision.py`
- Create: `docs/framework-upgrade/reports/p0-probe-a.md`（跑完再填）

1×1 PNG 的标准 base64（公开测试像素，不是密钥）：

`iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mP8z8BQDwAEhQGAhKmMIQAAAABJRU5ErkJggg==`

- [ ] **Step 1: 写脚本（不打印 Key、不打印完整 data-url）**

```python
#!/usr/bin/env python3
"""P0 Probe A: MiniMax-M3 vision via official Anthropic Messages (bypass gateway gates)."""
from __future__ import annotations

import json
import os
import sys
import urllib.error
import urllib.request
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
PNG_B64 = (
    "iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mP8z8BQDwAEhQGAhKmMIQ"
    "AAAABJRU5ErkJggg=="
)


def load_env(path: Path) -> dict[str, str]:
    out: dict[str, str] = {}
    for raw in path.read_text(encoding="utf-8").splitlines():
        line = raw.strip()
        if not line or line.startswith("#") or "=" not in line:
            continue
        k, v = line.split("=", 1)
        out[k.strip()] = v.strip().strip('"').strip("'")
    return out


def main() -> int:
    env = load_env(ROOT / ".env")
    key = env.get("MINIMAX_API_KEY") or ""
    base = (env.get("MINIMAX_ANTHROPIC_BASE_URL") or "").rstrip("/")
    if not key or not base:
        print("FAIL missing MINIMAX_API_KEY or MINIMAX_ANTHROPIC_BASE_URL")
        return 2
    url = base + "/v1/messages"
    body = {
        "model": "MiniMax-M3",
        "max_tokens": 64,
        "temperature": 0,
        "messages": [
            {
                "role": "user",
                "content": [
                    {
                        "type": "image",
                        "source": {
                            "type": "base64",
                            "media_type": "image/png",
                            "data": PNG_B64,
                        },
                    },
                    {
                        "type": "text",
                        "text": (
                            "You are given one image. If you received image input, "
                            "reply with exactly: VISION_OK. Otherwise: VISION_MISSING."
                        ),
                    },
                ],
            }
        ],
    }
    data = json.dumps(body).encode("utf-8")
    req = urllib.request.Request(url, data=data, method="POST")
    req.add_header("Content-Type", "application/json")
    req.add_header("x-api-key", key)
    req.add_header("anthropic-version", "2023-06-01")
    try:
        with urllib.request.urlopen(req, timeout=60) as resp:
            raw = resp.read().decode("utf-8", errors="replace")
            status = resp.getcode()
    except urllib.error.HTTPError as e:
        raw = e.read().decode("utf-8", errors="replace")
        status = e.code
    except Exception as e:  # noqa: BLE001
        print(f"INCONCLUSIVE transport {type(e).__name__}")
        return 3
    text = raw.lower()
    # Never print API key; truncate body
    snippet = raw.replace(key, "***")[:500].replace("\n", " ")
    print(f"status={status}")
    print(f"body_snippet={snippet}")
    if status == 200 and "vision_ok" in text:
        print("SUMMARY PROBE_A=PASS")
        return 0
    if status in {400, 404, 415, 422} or "image" in text and "not" in text:
        print("SUMMARY PROBE_A=FAIL")
        return 1
    print("SUMMARY PROBE_A=INCONCLUSIVE")
    return 3


if __name__ == "__main__":
    sys.exit(main())
```

### 2a: env 门控注入（默认关）

- [ ] **Step 1: 在 `feature_flags.py` 增加读取（空则关闭）**

```python
def p0_probe_b_marker() -> str:
    """Non-empty => inject this exact token into messages in pre-call. Default empty."""
    return (os.environ.get("P0_PROBE_B_MARKER") or "").strip()
```

- [ ] **Step 2: 在 `async_pre_call_hook` 里、`enforce_pre_call_gates` 之前注入**

只改 text 块或 string content；不打印 messages。marker 必须来自 env，不要写死进仓库默认配置。

```python
from shared_quota_router.feature_flags import p0_probe_b_marker

def _inject_p0_probe_b_marker(data: dict) -> None:
    marker = p0_probe_b_marker()
    if not marker:
        return
    messages = data.get("messages")
    if not isinstance(messages, list) or not messages:
        return
    last = messages[-1]
    if not isinstance(last, dict) or last.get("role") != "user":
        return
    content = last.get("content")
    suffix = f"\nIf you see token {marker}, reply with exactly that token."
    if isinstance(content, str):
        last["content"] = content + suffix
        return
    if isinstance(content, list):
        for block in reversed(content):
            if isinstance(block, dict) and block.get("type") == "text":
                block["text"] = str(block.get("text") or "") + suffix
                return
        content.append({"type": "text", "text": suffix.strip()})
```

在 `async_pre_call_hook` 中：`inject_protocol_into_data(...)` 之后、`enforce_pre_call_gates(...)` 之前调用 `_inject_p0_probe_b_marker(data)`。

- [ ] **Step 3: mock 只记布尔命中**

在 `MockHandler._record` 中：

```python
blob = json.dumps(body, ensure_ascii=False)

```

### 2b: B-lab（mock 上游，推荐作为 B 的硬证据）

需要一条 Messages 部署的 `api_base` 指向 mock（`http://127.0.0.1:18080`）。不要改生产 MiniMax Key 指向。做法：用现有 contract 习惯，**临时** overlay 仅用于探针会话，或对 `glm-5.2` 起一个隔离 proxy。

最小实验室路径（不改用户 `plans.yaml` 生产套餐）：

1. 终端 A：`.\.venv\Scripts\python.exe -m shared_quota_router.mock_provider --port 18080`
2. 用已有 contract 测试同样的 Router+callback 注册，对 mock 发 `anthropic_messages`——若该路径不经过 **proxy HTTP `/v1/messages`**，则**不能**单独当作 P0-B PASS（只能当 hook 单元证据）。

**P0-B 的 PASS 必须以 live proxy 的 `POST http://127.0.0.1:4000/v1/messages` 为准。** mock 用于「上游出口」时，必须是 **proxy 的上游**，不是绕过 proxy 的 SDK。

因此 B-lab 的正确做法：

- 复制一份仅探针用的 `litellm` overlay 太重。更简单：在 mock 上增加命中记录后，把**一台本机已有 Messages 模型**临时 `api_base` 改到 mock **仅用于探针窗口**，测完立刻改回。计划允许：用 `glm-5.2` 的一个 deployment 临时指向 mock 会中断该模型，故默认走 **B-live 回显**；B-lab 作为可选加强。

**本计划将 B-live 回显定为 V1 必做；B-lab mock 作为若回显 INCONCLUSIVE 时的加测。**

### 2c: B-live 脚本

- [ ] **Step 4: 写 `p0_probe_b_precall_mutate.py`**

脚本职责：

1. 生成 `marker = "P0B_" + secrets.token_hex(6).upper()`
2. `os.environ["P0_PROBE_B_MARKER"] = marker` **无效于已启动的代理进程**。必须把 marker 写入代理进程环境并**重启代理**，或代理启动时已读 `.env`。

**执行约定：** 探针前在 `.env` 增加一行 `P0_PROBE_B_MARKER=P0B_TESTONLY1`（测完删除），然后 `.\scripts\llm-router.ps1 stop` / `start`。脚本从 `.env` 读同一个值，客户端 body **不**包含该值。

3. `POST /v1/messages`，headers：`x-api-key: $LITELLM_MASTER_KEY`，`anthropic-version: 2023-06-01`
4. body：`model: MiniMax-M3` 或 `glm-5.2`（纯文本、无图），user content 仅为：`Reply with exactly: pong`（不含 marker）
5. 解析响应 text；若含 marker → `PROBE_B=PASS`；若含 `pong` 但不含 marker → `PROBE_B=FAIL`（模型按客户端原文答了，注入未到上游）；其它 → `INCONCLUSIVE`

注意：若注入成功，模型更可能回 marker 而不是 pong。FAIL 判定「只有 pong、没有 marker」是强 FAIL。

```python
# 核心请求（完整脚本同 probe_a 的 env 加载风格）

}
```
