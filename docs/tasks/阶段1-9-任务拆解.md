### 跨阶段契约（拆解层钉死，与 v0.2 §0.3 一致）

#### RequestRoutingContext（P5-T1 定义；P7 读 / P8 写）

```text
request_id: str
tried_quota_groups: set[str]
first_byte_sent: bool          # 默认 False；流式/响应已有字节后置 True
max_quota_groups: int = 3
```

语义：

1. 同 request 内同一 `quota_group` 最多尝试 **1** 次  
2. 不同 group 最多 **3** 次  
3. `first_byte_sent=True` → **禁止**跨 deployment 重试/切换  

#### FailureKind / FailureClassification 归属

- **唯一权威**：`plugins/shared_quota_router/classifiers/base.py`  
- **禁止**在 `models.py` 重复定义  
- 故 P6 与 P5 **可真并行**（P6-T1 不依赖 P5-T1）

#### 契约测试运行环境（C0/C1 防空转）

任选其一并写入项目文档（P7-T1 钉死）：

1. dev 依赖安装与 `v1.90.5` 对齐的 `litellm`，或  
2. `PYTHONPATH` 指向 `upstream/litellm`（submodule）  

P7-T9 / P8-T9 验收必须给出 **一条可复制且全绿** 的命令（如 `pytest tests/contract/test_c0_*.py -q`）。
